# 给 Codex 的安装说明：v0.5.13 程序包

请先将 ZIP 全部解压到可写的本地目录，然后运行 detail-workbench/install.cmd；安装完成后用同目录 start.cmd 启动，确认标题为 v0.5.13。

这是不含母版的程序包。已有五套母版的用户应使用“v0.5.13-含5套母版-Windows.zip”完整包；该完整包还携带母版补充字体。

本包用户需自行上传 PSD／PSB 母版。工作台会在副本上仅保留必要模块，原始文件不改动；正常预览使用精简后的母版示例，不显示完整原稿的多余页面。

新电脑需安装并能正常使用桌面版 Photoshop。首次安装会建立本机 .venv 并安装依赖与基础字体。不要复制其他电脑的 .venv。字体安装后如 Photoshop 已打开，请先保存用户文档再重开。不要结束有未保存文档的进程。

如已有工作台与个人资料，先保存资料包再升级；保留个人模板、资料与输出目录。出现问题请查看 install.log，不要删除用户文件。

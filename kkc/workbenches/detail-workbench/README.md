# 详情页套版工作台 v0.5.11

Windows 本地工具。导入一款商品资料，选择母版并绑定图片，在右侧预览后生成可编辑 PSB。

## 使用流程

1. 双击 start.cmd。窗口标题应显示 **v0.5.11**。顶部「刷新工作台」可载入程序更新，保留当前字段、表格、图片绑定、所选母版、输出位置、当前页面及未保存草稿；新版恢复成功后旧窗口才会关闭。恢复失败时保留旧窗口。刷新不会代替「保存当前资料包」。尚未提供刷新按钮的旧版本，需要保存后手动重开一次。
2. 点「导入资料包 / JSON」，选择完整商品资料文件夹、ZIP 或 JSON。还没有本地资料时，同一窗口内点「让 Codex 整理资料」，填写飞书链接、当前视图行号和结果目录，复制任务给 Codex。完成后导入整理结果。此流程使用已登录浏览器，无需手填令牌或创建飞书应用。
3. 选择母版。右侧「母版版式」展示原始母版完整参考画面；导入商品后切到「预览」，展示当前商品及其图片、表格；「成品」展示 Photoshop 实际导出的 JPG。
4. 资料导入后会在后台检查，不打断当前编辑；提示和缺项在「检查结果」查看。点击「生成可编辑文件」会再次检查最新资料，通过后调用 Photoshop。

Photoshop 保存时出现旧版本外观兼容性信息提示，可确认后继续。工作台处理超过一分钟会提醒检查 Photoshop 是否有待确认窗口；这不等于文件已生成，只有保存并重开核验通过才显示成功。

上传母版时，底部显示当前解析步骤。单个步骤连续 3 分钟无进展，或单次 Photoshop 调用超过 10 分钟，工作台会结束等待并提示最后一个步骤。Photoshop 恢复响应后可重新上传。

完整原稿预览优先读取 PSD / PSB 内已保存的合成图；文件没有真实合成图时再由 Photoshop 生成。量体图名称使用逐项匹配，避免 Photoshop 2020 在复杂名称规则上停顿。整理长版母版时使用图层 ID 选择与删除工作副本中的分组。

「试用马甲样例」可载入已有配图，方便体验。正式资料与样例应分别保存。

## 图片绑定与自动排版

- 在左侧「图片匹配」选择图位，再选择或替换图片；双击图片列表也可更换图片。图片区不再设置「调整所选图位取景」「重新定位素材目录」按钮。
- 绑定后的模特图、场景图和独立主视觉照片，自动按母版图框等比填满、居中裁切，保留图框蒙版。右侧预览与 Photoshop 使用同一套默认构图规则。
- 界面不提供手动缩放、拖动或取景组件。旧资料包或刷新会话中的手动取景状态会被忽略，图片使用当前默认自动排版。
- 商品透明图保持完整主体展示，并统一同组商品的可见大小。主视觉默认使用第一色商品图，绑定或更换模特图不会改变主视觉；也可以为主视觉单独选图。品牌场景未单独绑定时跟随模特图1。
- 母版识别出「量体示意图」图位时，导入资料包会自动带入已确认的图片。也可以在「图片匹配」里选择该图位并绑定 PNG 或 JPG。示意图等比完整放入。没有绑定时沿用母版示意图。
- 「尺码备注」可单独编辑，随预览更新，生成 PSB 时保留为 Photoshop 文字图层。
- 母版识别出 STEP1 属性组件时，可编辑版型、触感、厚度和弹性。留空的项目沿用母版示例值。
- 生成后会重新打开 PSB，核对尺码表、量体图和备注的实际图层边界。尺码区的间距与备注可编辑状态写入「素材与套版记录.json」。
- 选择或替换图片后自动切到当前商品预览并定位该图位。未绑定图位的添加提示不进入成品。未提供模特图时不借用母版中的旧款照片。
- 原始图片文件不改变，成品中的图片保留为嵌入式智能对象。素材分辨率偏低时会提示，请按提示更换高清原图后核对「成品」。
- 图片读取失败会显示具体原因并支持点击重试。图框蒙版无效时显示提示并暂用矩形预览；上传母版时会检查蒙版非空，避免照片被透明蒙版隐藏。

## 母版参考与实际套版

「母版版式」使用原始 PSD / PSB 的完整快照，包括原稿中的场景和模特示例。它用于查看参考设计，示例照片不自动用作当前商品素材。

「预览」由母版解析提取的固定背景、图框轮廓和透明前景，叠加当前商品图片、文字和表格生成。灰色图框来自母版设计，「模特图N · 未绑定」是界面提示，未绑定提示不进入成品。「成品」显示 Photoshop 实际导出的整页 JPG。

已识别的模特区绿线默认保留。在「预览」里右键绿线，点「删除此装饰」；需要撤销时，右键预览空白处恢复。该设置随当前商品资料包保存，并应用到该商品使用此母版生成的成品。母版原稿、Logo、品牌文案和图片绑定保持原样。

工作台另存套版工作副本和静态底图，按当前商品颜色数量、表格行列及已绑定模特图调整模块。母版原稿的画布尺寸可能与工作副本不同，界面会说明。无法取得原稿时明确提示，不能把清理后的空白图位冒充完整原稿。

「上传本地母版」支持 790 px 宽、兼容图层结构的 PSD / PSB，包括新版小山行风感洞洞裤及较早的「产品信息」「产品信息T」母版。上传后保存在本地母版库。表格沿用该母版实际 S / STEP 标题和设计；无法识别的母版会报告原因。

另支持商品信息、尺码表、试穿报告和尺码快选分别放在顶层分组的平铺母版，包括“小糯云冰奶皮防晒 t 详情”文件中的实际版式。识别按模块和图位结构核对，保留原稿里的标题和表格顺序。“码段”字段对应商品资料中的“尺码”。长原稿中的旧商品宣传与检测卖点保留在完整原稿预览，工作母版整理为页头、商品信息、颜色、尺码、模特、品牌与页尾，整理范围列在检查结果中。

商品信息也支持嵌套分组，材质、尺码快选和试穿报告按母版实际模块处理。母版没有的字段在界面中只读，未设置的表格标签会收起，原商品资料仍可随包保存。颜色区尚未放图时，可依据色名位置与留白建立商品图位，并在检查结果中提示。帽围测量图文与主要尺码备注分别保留，旧模特姓名、身高和体重会从套版工作副本清理。

上传先校验结构，再整理工作副本。未匹配的设计会显示「母版结构需要配置」，分组报告和可读取的原稿参考保存在本地母版库的 `.diagnostics` 子目录。完全不同的自定义版式需要核对图位，工作台会报告缺项。

经典母版也支持已生成的「03选尺码（可编辑）」「05尺码快选（可编辑）」原生表格结构。导入器按模块及表格结构匹配，匹配失败会说明未定位的模块，不把整个文件误称为不可编辑。旧款照片按所属照片框组及图层类型清理，避免因照片碎片较小而遗漏。

商品支持 1–8 色，超过四色分两排。模特图最多四张，按图位顺序绑定。数据缺失保留为空并提示；未提供试穿数据时收起对应模块。

## 资料包与迁移

迁移时复制整个商品资料文件夹或 ZIP，不要只移动 JSON。相对图片路径以 product_data.json 所在目录为基准。完整格式见 product_data.example.json。

assets.products 为色名与相对商品图路径的对应，assets.scenes 按图位顺序最多四张，assets.hero、assets.brand 可另指定主视觉、品牌场景。assets.measurement 填单张量体示意图的相对路径，例如 `素材/量体示意图.png`，缺少或待核对时可填 `null`。source_note 保留来源链接和行号。views 可省略，旧文件中的手动取景信息不应用于当前预览或生成。

从飞书整理时，把完整尺码表附件保存到 `原始附件/尺码表/`。尺码数据照常整理成可编辑的表格矩阵，原表备注按原文和换行录入顶层 `size_note`。缺省或填 `null` 时沿用母版原有备注，填 `""` 时清空备注。

量体示意图优先使用该行的独立原图。示意图嵌在尺码表截图中时，可从下载的原图单独裁出完整图示和量尺标注，并在 `source_record.json` 记录来源和裁切范围。款式或图示边界待确认时，在 warnings 中写明，之后可在工作台手动选图。

「保存当前资料包」保存新的 ZIP，包含编辑后的商品数据、图片绑定和原始图片、原始附件及所选母版记录。重新导入可继续编辑。「资料路径与缺图检查」可以查看实际来源，缺图时在该窗口重新定位素材目录；同名文件不能唯一匹配时需手动选图。

工作台本身也需完整复制到其他电脑，以保留母版库、字体及程序文件。商品资料包不包含母版 PSB。新电脑通过 Codex 读取新飞书资料时，在浏览器登录有访问权限的账号即可。

## 输出与环境

每次生成使用独立的款号目录，包含 790 px 宽的 PSB、500 px 宽的整页 JPG 和来源记录。图片是嵌入式智能对象，商品文字、颜色名和表格是 Photoshop 原生文字层。交付前用「成品」检查实际输出。

需要 Windows、Python 3.10 或更新版本（含 Tcl/Tk）、Pillow 及可通过 COM 调用的 Photoshop。字体沿用 FZLTZHK--GBK1-0、G8321-Medium 和 KocoDetailFangYuan-SemiBold。安装 Pillow 后运行 app.py，日常使用 start.cmd。

# 同款不同色：选场景与套版

目标：为每个“款号＋颜色”选择合适的真实场景素材，组合对应产品小图和颜色文字，生成版式一致、场景构图适配各自素材的图片。

## 核心规则

- 场景图是变量。不同款号、同款不同色都可以使用不同场景，不默认共用同一张背景或模特照片。
- 每个输出绑定一个款号和颜色；产品小图、场景中展示的产品、颜色名称应一致。
- 不根据文件顺序配对。先用款号、颜色及用户对应表筛选，再目视核对产品结构与可见配色；文件名只是线索。
- 固定的是用户指定的版式元素，例如右侧卡片、底部波浪、文字样式。卡片的位置是否可动，服从模板或用户要求。
- 场景可以是完整模特照片，也可以是用户指定的其他场景类型。完整照片通常作为底图，无需先抠出人物。
- 保留原始素材。未得到改色或生成场景的要求时，使用现有素材；缺色不能靠自动改色补齐。

## 1. 读取素材与版式

先查用户已提供的文件、目录、说明和可访问的模板，复用已有参数。只询问影响执行且无法从素材确定的信息，不要求用户重复填写全部选项。

建立素材清单：款号、颜色、产品小图、场景候选、模板、目标尺寸及输出位置。批量任务使用 [references/task-format.md](references/task-format.md) 记录匹配、选择及构图，避免多轮反馈后混用旧版本。

模板处理：

- 有分层模板：检查实际图层，将场景、产品小图、颜色名称映射到对应图层；保留已有装饰及样式。智能对象是否能替换，应以实际文件和工具能力为准。
- 只有成品 JPG/PNG：将其作为版式参考，重建卡片、装饰、产品及文字层。不能宣称已还原被遮住的场景或原始可编辑文字。
- 未指定尺寸时，优先沿用模板尺寸；无模板时可提出 800×800 作为预览方案，并明确这是可调整的默认值。
- 无素材或模板路径时，请用户提供必需材料，不把聊天示例文件名当作真实文件。

## 2. 按产品和颜色选择场景

先做身份筛选，再做构图选择：

1. 确认产品小图对应款号和颜色，结合用户映射、素材分组及可见产品细节查找场景候选。
2. 佩戴或使用场景中可见产品时，核对款式、结构和配色。款号不符或明确不同色的候选应排除；曝光和光照差异不能单独作为错色结论。
3. 背景场景中没有可见产品时，按用户指定的产品用途和画面要求选择，不能将其记录为“已验证同款同色佩戴图”。
4. 在匹配成立的候选中，优先选择产品展示清楚、清晰度足够、姿势适合版式、能保留脸部及关键产品、卡片覆盖区干扰较少的图片。
5. 每个款号和颜色独立选择。一个候选明显更合适时先选它并说明理由；多个候选接近时生成标有候选编号的联系表，请用户选择，同时继续处理其他已明确的项目。

无法确认的项目标记“待确认”，列出具体疑点和候选，不把相近款或相近色自动视为正确匹配。部分缺图时继续完成有完整素材的预览，并单列缺失项。

## 3. 按所选场景调整构图

- 等比缩放并针对每张素材设置裁切位置，不统一套用中心裁切，不拉伸人物或产品。
- 裁切应优先保留产品、脸部及与展示相关的手部。检查卡片实际覆盖区域，而不只看原图是否有留白。
- 版式允许调整卡片位置时，可以在允许区域移动；固定卡片时优先更换候选或调整裁切。都无法满足时列为构图冲突，给出可选预览，不悄悄改动固定版式。
- 产品小图按可见主体边界对齐并等比缩放，避免不同透明边距导致一大一小。保留细带、透明镜片和浅色边缘；检查是否误把产品白色部件当作背景去掉。
- 颜色名称使用独立文字层，沿用模板字体和对齐。文字过长时在版式允许范围内调整字号或布局，避免溢出。
- 记录源图尺寸、缩放/裁切、产品位置及文本布局；用户后续只改一项时复用其余已确认设置。

## 4. 配对与套版预览

先提供配对清单及套版预览，可以放在同一张联系表中：每项显示款号、颜色、所选场景编号、产品小图与最终构图。选图有歧义时附候选预览。

在发送前目视检查：

- 产品小图、场景中产品和颜色名称匹配；未验证的项目已明确标注。
- 裁切及卡片没有遮住关键产品或脸部；产品小图尺度和版式一致。
- 透明产品边缘完整，文字无错字、缺字或溢出。

用户确认选图及版式后再生成正式批次；同批已有确认直接沿用，用户明确要求跳过预览时遵从其要求并完成自身检查。修改了场景、裁切、产品图或文字的项目应更新预览和记录，不能继续沿用旧的确认状态。

## 5. 生成与交付

选择能保持模板效果的可用工具。普通图层叠加、排版和批量导出可以后台完成；需保留 PSD 的智能对象、可编辑文字或特殊效果时，使用能真实保留这些结构的工具。不要把普通像素层 PSD 描述为具有智能对象和可编辑文字的模板。

需要调用 Photoshop 时，先确认用户当前的使用安排；不修改或关闭用户已有文档。能后台完成的步骤继续后台执行。只有在用户要求生成新图、生成式修改等需求时，才另行调用相应图像生成流程。

按用户指定格式和尺寸导出；未指定时，以确认过的预览参数为准。文件名优先包含款号和颜色。输出到新目录；已有同名输出时创建版本或沿用用户已指定的覆盖策略，保留源图。

交付成品、最终预览和素材对应记录。记录每张成品使用的场景、产品图、文字及构图参数，并说明仍待确认或因缺图未生成的项目。只有实际写入并检查过的文件才能列为已交付。

# 服装空模 SKC

让同款同视角的空模图在角度、轮廓和摆放上统一，同时保留每个颜色真实的商品细节。使用当前环境的 ImageGen 编辑图片；需要保留原始商品像素时走 PS 精修。Nano Banana 可在用户要求时作为试跑对照；未接入时不声称已调用。

1. **接收素材和目标。** 首次收款号、视角、各色对应的高清实拍及目标规格。带模特或假模的原片可用。先确认用户实际指向的图片和版本：实拍原片、参考截图、既有成品和本轮生成图各有用途。尺寸和背景沿用本批已确认规格；首次未指定时可先做白底预览，交付规格在需要时补齐。罗纹、绒面、亮面、网眼、细格纹等易失真的区域，优先用同色同部位的清晰近照。
2. **选首色并生成空模预览。** 优先选视角合适、细节最完整的一色。以本色实拍为编辑底图，去除人体、假模、支架和别针，整理临时褶皱或塌陷。保持真实透视、比例、结构和设计上的不对称；印花、标识、五金、拼色、织纹和缝线以实拍为准。局部缺口只按可信参考补齐，重要但无依据的部分标为待核。用 [生成与核图指引](references/imagegen-and-qa.md) 准备提示词、对照首图。
3. **修正并锁版。** 只错一个小区域时，带局部参考定向修一次；整体角度或轮廓错时，修正参考和构图后重做预览。若印花、结构或整件材质被改动，或局部修正后仍偏离实拍，转 PS，以高清实拍为底保留真实像素，仅处理假模、边缘和有依据的缺口。没有可用的 PS 执行路径时，输出明确的修图位置和参考，不把待修图列为合格。用户确认后，保存母图与简短记录：款号、视角、版本、参考文件、锁定项与确认状态。单色试做也可在预览阶段结束；未确认的图只作候选。
4. **补色或批量套版。** 同款同视角用“已确认母图＋目标颜色实拍＋必要的局部参考”逐色处理。母图只定义角度、轮廓姿态、摆放和光影；该色实拍决定颜色、拼色、面料、印花、五金和结构。两者冲突时保商品真实性，无法兼顾时标注并给出可核对的预览。首次扩批先试一张拼色差异明显或材质最易跑偏的颜色，通过后再做其余颜色。新视角单独锁版；单独补一色可直接用原母图并按色验收。
5. **按色验收与交付。** 对照本色实拍看整图和关键局部，查版型、配色、材质、印花、缝线和去模后的边缘。按要求输出白底 JPG/PNG、透明 PNG 或两者；核对文件实际尺寸、格式、背景与命名，透明图检查真实 Alpha 和边缘。首批附已确认母图和锁版记录；交付清单列款号、颜色、视角、文件及待核项，PSD 仅在需要时交付。

## 已有结果的尺寸和清晰度

- 用户指向已有的生成结果时，先定位原输出文件，按指定版本处理；可辨认的聊天截图只用于定位。只要大图时等比缩放，按已确认构图处理宽高比差异。保留整张白底图且目标更长时可补白，禁止拉伸衣服。保留上版和新版本，注明实际像素及是否重采样。
- SKC 高清交付先执行[材质保真与伪影拦截流程](references/super-clarity.md)。从未增强的完整空模母图出发，AI 超分先作候选；检查网眼、包边、Logo、拉链与普通面料后，仅在通过的区域保留增强。预览确认、锁版和逐色验收继续沿用上述步骤。只改尺寸时按原规格等比处理，不强制 AI。
- “超级清晰”以实拍支持的细节为准。网孔变粗或弯成大格、断裂纹、白色碎斑、黑描边、Logo 走样任一出现，该候选不得直接交付；回到当前有效的未损坏母图重新处理，不在错误纹理上继续叠加超分、锐化或磨皮。
- 默认用完整母图作底，增强放在独立完整画布图层及可编辑材质蒙版中；网眼、反光包边、Logo 和背景按实际位置保护。未核准区域不得进入增强允许区。用原生 Photoshop 保留正常褶皱、颜色和反光，不把全部白亮针脚当瑕疵抹掉。
- 原有拉链清晰增强只用整图已有像素、局部滤镜和蒙版；不单独生成、重建、导入或贴回另一条拉链。历史 400% 智能锐化只保留为个案记录，不作为通用或默认设置。用户不需选择技术参数；执行者看同尺度小样后选取克制强度。
- 已有合格成品仍偏软时，优先读取[区域清晰增强](references/regional-definition.md)，在当前有效 PSD/PNG 上续修，保留上一版所有有效图层，不重新生成整件或重跑全图超分。网眼、帽沿等默认保护部位被用户明确点名后，可作为本轮限定增强区，不能继续以整块零改动代替清晰提升。
- 区域增强先验证既有网孔、折边或齿纹是否有可用像素，再做小半径原位去模糊和独立蒙版；可用变暗混合限制新亮边，另查黑描边和粗纹。白底边界须从修复蒙版排除，原有反光保留。未见新白斑或假格纹且实际更清楚才保留，不能只以“没有改动”判通过。
- 默认入口 `scripts/Invoke-WholeImage.ps1` 使用绑定源图哈希的区域配置与候选核图状态；未检查或拒绝的候选会被拦截。`Invoke-AiCandidate.ps1` 仅准备候选，不能把其输出自动认作成品。区域配置和核图由执行者填写，不新增用户批准环节。
- 最终 PNG 和重开的 PSD 都须核对：实拍符合、同材质连续、无新伪影、保护区像素不变。像素一致性与程序成功不能代替目视验收。记录母图、候选、问题图、输出的身份、尺寸和处理方法；AI 增强不能写成找回了未拍到的真实细节。

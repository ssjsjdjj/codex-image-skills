# 按文件名替换图片｜精简介绍

**技能名称：** `replace-images-by-name`

**目的：** 将选定的小图、缩略图或临时图替换为对应的原图或高清大图，减少逐张查找、复制和核对的重复操作，并保留可恢复的原文件备份。

**适用场景：** 电商选图完成后换回大图、按文件名恢复高清素材、同名源图批量覆盖。此流程不生成清晰度、不抠图、不修图。

**输入：** 小图目标目录、大图源目录、需要处理的范围。按“第几张”指定范围时，应说明或核对排序方式；未明确方向时先厘清哪个目录需要被覆盖。

**流程：** 核对目录与范围 → 精确同名匹配 → 生成替换清单 → 备份原文件 → 用大图覆盖小图 → 校验文件一致性 → 按需生成对比预览并确认。

**关键规则：** 默认完整文件名一致才匹配；缺失或多义匹配先解决；特殊后缀和非精确映射需对应授权；每张替换前先备份，替换后用SHA256核验复制一致性。

**交付：** 已替换图片、原文件备份、替换清单和校验结果；对比预览按需追加。

**一句话调用：** “使用按文件名替换图片技能，小图目录为……，大图目录为……，处理指定范围的图片，并生成替换前后对比预览。”

**实现说明：** 当前原版脚本没有序号范围参数；指定局部范围时，需在工作副本中显式限定目标文件，并保留原有备份与校验。对比预览为按需追加处理，不是原版替换脚本的内置输出。

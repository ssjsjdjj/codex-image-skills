# 局部生成与合成

## 开始前锁定的依据

按图、按帽简记这四项：

| 项目 | 要记录的内容 |
| --- | --- |
| 修饰范围 | 如中心橙帽的后片翻起、左侧脸旁的急折、后背右侧折影 |
| 稳定锚点 | 前檐侧标、后开口包边、护颈片缝合起点、发际线、原肩线 |
| 同款实拍 | 同色匹配布面和印花，同角度匹配接缝、遮挡和长度 |
| 可调整范围 | 帽布的轮廓、原轮廓移开后露出的少量背景、必要的接触阴影 |

一张带多人时，不把所有帽子套成同一形状。处理侧脸近景时，保持前檐遮挡和原来的护颈片终点。处理背面大特写时，印花、字样和原织纹比显著拉直褶皱更重要。

## 生成只解决轮廓需要重建的部分

用完整原片作合成底。裁切生成目标时保留接缝、完整新旧轮廓及必要的邻近背景，记录裁切坐标，方便回贴。原片、同款参考、不同款动态参考分别说明用途。避免仅用整图低分辨率生成结果回贴商品特写。

按需组装下列提示词。简化到所选部位，不应用给画面里其他帽子：

> 第一张是唯一要修的原片局部，保持构图、透视、位置和原光线。第二张只参考同款护颈片与帽檐的接缝、包边厚度和布料垂感。只调整［具体哪顶帽与哪块布］。从［真实缝合点或侧标］往后，主要布面［如何下落］，末端［向外或向上多少］。前檐、侧标、脸、发丝、领口、衣服和邻近物体保持原样。新露出的区域延续原背景的海平线和纹理。保留原色、原布面的细织纹和受光梯度，包边细且连续，布面与衣服有清楚遮挡，只有合理的窄接触阴影。网眼只出现在真实的内侧位置，保持原有印花归属和可见性。

- A 候选示例：末端低于被吹起的原顶点，主体从连接点向后下方走，外端留一段自然上扬。保留原来的软布重量和折痕。避免整片横飞、硬翘或卷筒。
- B 候选示例：主要布片靠近颈肩，延续同款真实长度，边缘只留一小段轻翘。避免拉长到肩胛或袖子、画成硬板，或把内网当外布。
- 不给定固定像素或角度当作通用标准。不同帽型、姿势、裁切和拍摄距离，允许的变化幅度不同。

## 候选合成

1. 先按稳定地标对齐候选与原片，核对坐标和缩放。袖子、人物和背景的位置不同，说明候选只可作为局部素材。
2. 必要时把旧折片遮挡后的区域与新布片分层。布片边沿根据真实包边和遮挡勾出。真实边缘用与原图焦点相当的过渡，海面等空背景按纹理另处理，别用一条宽羽化同时覆盖布面和衣服。接触阴影窄而自然。
3. 印花附近优先采用整体原布面局部明暗，不在重绘布块上叠一块原印花。只调明暗时使用可编辑的调整图层或原图像素蒙版，把织纹、颜色和目标外部保住。
4. 汇出后按 100% 检查几处交界。旧包边残留、假双线、手或脸被截、外侧凭空出现网眼、印花漂移、布面和肩线融在一起都需要回退或重新收边。不要通过放大、锐化或加假纹理掩盖。

## 可选的像素与 PSD 验证

如果使用 RGB PNG 和 Photoshop 文件，可用 Python 环境中的 Pillow、NumPy 和 psd-tools 验证实际导出文件。下面的名称须替换成 PSD 顶层图层的确切名称，也可以指定档位根组。档位上的栅格蒙版应直接控制对应档位的全部修改范围。命令只读，不制作图像：

```powershell
python scripts/verify_exports.py --source original.jpg --psd retouch.psd --base "原片" --variant "A" "A.png" --variant "B" "B.png"
```

默认要求原片和蒙版外像素一致，允许导出和 PSD 重算有 1 级舍入差。若原片经约定的色彩空间转换，先将图层底和验证用原片统一到共同的交付色彩空间，再检查。用于场景图主观质量判断时，另外查看产物中的轮廓和面料。

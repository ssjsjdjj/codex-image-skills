# 防晒帽减风精修

从拍摄原片直接出发，把减风、合成和原尺寸复核做在首次交付里。这个技能独立完成这项工作，无需启动商品差异检查或另开差异修复流程。

## 定位与参考

- 先记录要处理的图号、帽子和排除项。沿用用户已选的处理范围与风感档位。只提供参考的照片用于观察，不作待修图。用户只要一版就交一版。
- 认清帽冠、带车线的硬挺前檐、柔软护颈片、外布与内网、两者接缝和后开口。用同款同色原片判断印花、包边和颜色，用最接近视角的同款实拍判断长度、遮挡与接缝。不同款只能参考摆动方式。
- 逐帽识别异常。正常宽檐弧度、透视造成的放大、贴脸的原有折边、自然褶皱和真实景深可以保留。只修用户指定的帽子，人物、衣服、道具和场景以原片为底。

## 第一次制作就保住原片

| 原片情况 | 制作方法 |
| --- | --- |
| 帽型已自然，有深折影、局部鼓包或稍硬的折边 | 优先在原片上做小幅塑形或局部明暗修整。保留原有织纹、印花和折边连续性。 |
| 披风翻到帽冠上方、折叠遮住大部分帽型，或确需改外轮廓 | 只裁帽子和必要上下文作为生成目标。用同款参考约束外轮廓与面料，只取可用的帽布局部合回原片。 |
| 变形位置贴着脸、发丝、衣领、其他人物或标识 | 保持原遮挡锚点。边线无法对齐时缩小改动，回到原轮廓处理折影。 |

- 在 [局部生成与合成](references/local-retouch.md) 找提示词、合成边界和返工停止标准。仅需轻修时略过生成候选步骤。普通图片编辑按当前工具约束使用局部图像编辑能力，成图以原片和真实服装边界为准。
- 有 A/B 要求时分别设置明确落点。A 保留明显风感，让护颈片下缘向后外摆。B 缓和升起角度，让主体顺颈肩自然垂落，只留末端轻飘。在形态已合理的图里，两档可以只改变折影强弱，交付时说明。
- 开始合成前锁定原图底层。修改轮廓时把新布片和旧轮廓移开后露出的背景分开处理，按需要放在独立图层蒙版。印花和 Logo 优先保留原图，同视角中看不见的图案不要挪到可见面。
- 做完第一张代表图就读回实际导出的文件，在 100% 看跨布片的包边、织纹、肩部遮挡和背景连续性。只有质量合格才将同一原则用到其余图，逐张调蒙版和档位。用户已授权批量时，不因做了内测样张而停下来重复确认。

## 交付前检查

1. 在原片与实际导出的修后图之间比对，按图号看全图和原尺寸局部。100% 排查布料边缘发虚、色晕、双包边、假网眼、印花重绘、纹理突变、髮丝/衣领被吞，以及露出背景的地平线或纹理断层。需要时放大定位，把证据尺寸和成品尺寸区分开。
2. 同时看 A/B 的风感差别和实物结构。属于原片的包边可呈两层，先核对原片再判断双线。保留脸、发、衣服和背景像素，只有新旧轮廓造成的遮挡与回填区域允许局部变化。能够枚举蒙版时，使用 [导出校验脚本](scripts/verify_exports.py) 验证像素范围和 PSD/PNG 一致性。像素校验不代替目视验收。
3. 失败候选先定位原因，再做针对性修正。无法让新增区域自然衔接时，回退到原片或更轻的修法，并说明仍有限制的图号和部位。生成候选、缩小后的总览、仅有程序差异统计，都不能作为成品合格证据。
4. 交付实际修后成图及必要的原尺寸对照。用户要求 PSD 或前序已有 PSD 交付约定时，保留完整原图和可编辑局部蒙版，每档能独立开关，PNG 从对应档位导出。

# 飞书正文与章节证据

报告和案例稿分别以飞书文档链接作为交付入口，证据放入各自对应章节；某章材料较多时，统一存放在该章的一份飞书证据文档中。本文件规定交付布局，不代表已接通飞书或已上传材料；实际交付状态依照已执行的写入与核验结果记录。

## 主文档与章节证据文档

- 同时要报告和案例稿时，最终提供“Codex使用报告”和“案例提交稿”两份主文档的真实飞书链接；只要一种时只交对应主文档。
- 主文档中先写事实、判断或结果，紧接着放支持它的关键图证、反馈摘录或检查结果，注明对应样本、版本、日期及证据编号。证据不足按事实标明。
- **某个章节材料较多时，该章材料统一放入一份飞书证据文档。** 在该文档内用小标题按案例、样本、问题或材料类型分类，便于查看。默认不继续拆成多份证据文档，不以文件夹替代该章证据文档。
- 主文档该章保留关键证据与一句材料说明，添加“本章完整证据”链接。证据文档页首注明它对应的主文档、章节、报告期及证据范围，并提供返回主文档的真实链接。
- 证据较少时直接放进正文，不为了凑结构另建空文档。以可读性决定是否汇总，不设置固定附件数或强制截图数量。
- 证据导航就在相应章节，默认不额外交付第三份总索引。用户明确要求总索引时再生成；内部审计索引继续留在work。

章节证据文档推荐标题：“主文档名称—第N章章节名—证据”。正式标题按实际章节与报告期填写，正文不放占位网址。同一证据可被两份主文档引用，引用处说明支持的事实，原件不重复上传、不重复计成果或分数。同章的新材料补入既有章节证据文档，保留版本说明；先查已有远端记录，避免重复新建。

## 放在哪一章

固定报告采用用户最新确认的八节提示词，正文直接从“1. 个人基本信息”开始，以“8. 问题与提升空间”结束；文件名和飞书文档名称可保留报告名。以下只指导证据分布，不补回已取消的评分或提升建议章节。

| 主文档章节 | 放入的证据 |
|---|---|
| 报告第2节“检索与数据说明” | 实际来源类型、覆盖范围、报告期和去重依据的脱敏摘要 |
| 报告第4节“使用数据概览” | 支持各项数量与日期的可核查统计依据，注明口径与局限 |
| 报告第5—6节“场景分析、典型案例” | 相应任务要求、原始输入、关键过程、本人反馈、实际修改、同素材重输出和复验对照 |
| 报告第7节“产出清单” | 已确认版本的实际成品、检查状态、采用或验收反馈；未知状态保持未知 |
| 报告第8节“问题与提升空间” | 真实未关闭问题、失败结果、局限依据及相关改善方向；未执行内容标待验证，不另列计划或评分 |
| 案例稿的任务与 AI 参与 | 任务要求、原始输入和操作记录 |
| 案例稿的本人判断与复验 | 不合格版本、本人反馈、实际修改和对应版本的复验 |
| 案例稿的价值、应用与复用 | 同口径比较、真实采用、验收或复用记录 |


报告第1节的基本资料和第3节的一页结论保持简洁，必要时引用正文中已有的证据或章节链接。四类材料是导航分类，不是强制四附件：原始素材与要求、反馈与修改、最终文件与检查、实际验收或采用。沿用[correction.md](correction.md)的六步链和版本边界，不能用链接数量替代真实人工复验。

## 一章一份证据文档怎么编

1. 页首写章节、所支持的事实、材料范围、当前核验状态；正文按实际需要用小标题分组。
2. 每个证据块注明简短标题、证据编号、样本/版本、来源和它支持的事实，配可读图、反馈或检查结果。完整原件需保留时，在同一证据文档中放可访问附件或相应真实原件链接。
3. 同素材前后图并排或紧邻呈现，标清不合格版、实际修改、复验版及本人结论。AI检查与本人结论分开，不把计划或等待验收写成通过。
4. 仅放支撑该章主张的必要材料。原始完整日志、哈希、凭证、无关客户信息和内部机密不自动复制到飞书；审计原件及精确来源保存在本地work。
5. 主文档链接到该章证据文档；适用时进一步链接到文档内小节。链接不可访问或证据未上传时标待补，不把空文档、标题或登录页当作可读证据。

## 上传、核验与真实状态

优先复用已有飞书文档和已授权位置；本账号已选择“我的空间”，迁移到其他账号时重新核实实际目标。先完成正文与章节证据的整理，向本人展示当前稿件、证据范围和对应状态；本人对当前文稿的确认不能由图片可用、检查计时结束或旧版案例确认替代。

有可用且已授权的飞书写入方式、本人已确认当前稿件时，按既有“确认后交付”的授权处理并回传真实链接；同一范围不反复请求上传确认。内容或证据版本实质改变时先核对新稿。仅改变证据链接的实际地址而不改事实内容时，记录映射和回读结果即可。

当前没有可用连接时，先整理可导入飞书的正文和章节证据编稿，必要时制作内嵌图证的DOCX并渲染核对，状态明确写“正文已准备，飞书链接待生成”；不能把本地DOCX或本机路径称为已交付飞书链接。继续连接、登录或更改权限另按用户当次请求执行，不因设定布局就宣称连接完成。

真实创建或导入后，回读两类文档，核对主文档内容、关键图证、对应章节证据链接和目标位置，记录远端文档标识及链接。同章已有证据文档时复用；部分成功记录已有链接，仅续传缺项。创建结果不明时先查远端记录，不盲目重复创建。保留当前权限，不默认公开分享、扩大访问或给同事发消息。

最终只提供本次实际完成的主文档链接。尚未生成或未核验的部分明确待处理，不能填假链接或称全部上传成功；章节证据链接放在对应主文档章节中，用户无需另找总索引。

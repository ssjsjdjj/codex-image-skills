# Lovart服装模特图提示词

根据本次真实素材写可直接使用的提示词。将衣服质感、商品结构、可见Logo和指定人物身份作为核心约束；用具体可见证据表达，不把“严格、超清、4K”当作质感控制的替代。

## 输入与参考分工

- 接收原片／已授权素材路径、商品细节、动作图、场景图、标准Logo、待修图或已有提示词，并结合用户本次要求。按任务使用已有输入，不要求每次凑齐固定数量图片。
- 看过实际图片再描述具体外观。仅有文字或部分图片时，可以按已知需求和用户图号先改写，简短指出影响结果的缺项；不声称看过未读取素材。
- 沿用用户已经指定的图号与人物归属；新增参考或图号时保持实际上传顺序一致。区分人物身份、商品细节、标准标识、动作构图、背景环境的依据，一张图可以承担多个明确角色。
- 多人逐一绑定脸、发型、配饰、服装和颜色。动作图只提供动作时，不继承其中原人物的脸、发型与穿搭；原片中的无关道具也不自动带入目标场景。
- 商品、人物数量／年龄、颜色、面料、头部角度、动作、镜头、场景、比例和像素都由本次输入决定。不要继承其他任务的款号、品牌、人物或尺寸。

## 衣服、Logo与人物约束

- 先内部整理各套衣服的可见依据：衣面细纹及方向、表面反光、固有色、垂坠／挺括观感、褶皱，以及本款关键拼片、走线、领袖口或裤脚。将与本次相关的具体特征写进主提示词正文，让服装成为清晰主体，不只在结尾写“清晰服装材质”。
- 不从图片猜成分、功能或看不清的织法。面料本身平整时，不用粗织纹、颗粒或过锐白边制造清晰感；有光泽的商品不一律改成哑光。各套／各色服装按各自依据描述。
- 新动作的大褶皱服从身体姿态、受力和遮挡；微观纹理沿局部布面连续，版型与关键结构仍按原款。区分可对应原片、需要变形和缺少实拍证据的新露出部位。不把站姿大褶皱整片套到坐姿，不宣称叠纹理或锐化恢复了未拍细节。
- 服装亮部保留层次，关键结构不因过曝、强虚化、磨皮或涂抹而丢失。用户要求自然照片感时也不凭空加噪点。
- Logo／印花依据标准源稿或原片清楚可见部分，明确字形／图形、颜色、位置、比例和遮挡；被遮挡或无法辨认部分不猜补，不新增标识。缺少可核实源稿时，不承诺完整字标准确。
- 人物身份依据对应原片，保留脸型、眼鼻嘴比例、年龄感、发型及配饰。头部方向、表情和视线按本次目标；头部新角度缺乏实拍时，不把推测当作已经真实还原。保留用户指定的侧脸／仰头要求，不自行改成正脸以便修复。

## 动作与流程判断

- 同动作换背景：以保留实拍人物和衣服为目标，背景透视、接地和光照匹配原片；不额外重设计人物，也不把文字“保持不变”说成实际锁定像素。
- 局部改动作：写明变化区域和可保留部位；避免为改一只手而重新设计已正确的脸、服装或Logo。
- 大幅换动作／视角：先协调人体、商品结构和遮挡，再组织场景与质感。简单背景可以便于检查，但生成白底图仍是AI底稿。必要时指出需补的同人角度或服装状态，不无故中断能完成的编词工作。
- 保留用户明确的人数、位置、动作、视线和道具关系。用画面位置、接触点和高低关系减少解剖左右手混淆；未经看图，不新增“扶相机”等推测动作。
- 改动作、改视角或重打光会改变像素；不把它们与全人物像素完全不变同时当作可保证的条件。镜头和场景以用户要求／原片透视为准，不默认固定焦段或浅景深。

## 默认交付：一份、两部分

除非用户另行指定，输出一个完整版本，按以下两部分组织；在聊天内可直接复制，需要文件时默认一份UTF-8文本，不另交重复的“首轮简版”。

**第1部分｜主提示词（本轮直接发给Lovart）**

主提示词要自包含：在正文中交代本次实际图号分工、人物与商品归属、目标动作和构图、服装具体质感与结构、可见标识、身份、场景及用户指定输出规格。读过的事实与文字要求分清；必要的缺项说明简短放在该部分复制正文之外，不写进生成指令。用户明确规格时写入要求，但不宣称平台已经按此生成。

**第2部分｜局部返修词（按问题使用）**

只提供本次有必要的返修词，说明各自适用情况；不能把所有类别一次塞进首轮。区分结构正确但面料糊、结构已错误、人脸漂移、可见标识错误、动作道具错误及背景错误。用户明确只要某一阶段时按其要求缩减，不机械凑齐固定类别。

默认不增加第三／第四部分，不附独立PS处理、设置说明、质检清单、耗时统计或效果评分；也不改名后重新附回。内部仍检查参考归属、指令冲突与证据充分性。用户另行要求这些内容时，按该次范围处理。

## 边界与参考

此skill负责提示词，普通调用不自动上传、发送、生成图片或执行PS。未实际生成不得写“已出图”，未做对照不得给提升比例或把“质感要求”说成每次必然达标。平台回复的“完全锁定”不替代图像验证。

- 编写主提示词或局部返修词时，按需读 [参考写法](references/prompt-patterns.md)，填入当前素材事实，不直接输出占位符。
- 用户要求呼啦圈实例或核对该案例时才读 [呼啦圈示例](references/hula-example.md)。它是条件化示例，不能成为其他款式默认参数。

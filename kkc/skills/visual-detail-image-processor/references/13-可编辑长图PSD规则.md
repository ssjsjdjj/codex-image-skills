# 可编辑长图 PSD

每款生成一份独立的可编辑长图，沿用母版画布、模块顺序和固定设计。文案与表格内容使用 Photoshop 原生文字层。商品色图和场景图用独立的嵌入式智能对象，外框、蒙版和剪贴关系按母版复核。

## 准备输入

1. 记录母版路径、输出路径，以及所有要改的文字层和图片智能对象的完整图层路径。路径从顶层分组起，按组名和图层名逐级填写。若同一级出现同名候选，在自动化母版副本里明确命名。
2. 按商品核实产品信息、材质、色名、各类尺码、试穿反馈和洗护数据。源图识别结果须经过核对再写入任务。
3. 尺码表任务矩阵第一行是表头，后续每行是该表一行。快选表的第一列为行标题。各行列数一致，空格用空字符串或 `null`，区间和有前导零的值用字符串。
4. JSON 省略 `template` 时，使用 [当前母版配置](../scripts/template_profile.json) 中选定的默认版式。临时默认是 `小山行风感洞洞裤-终.psb`。工作区有本地副本时优先使用该副本，另可读取原 X 盘路径。完整画布 790 × 40000 px，任务的 `output` 使用 `.psb`。将配置中的 `default` 改为 `classic` 可恢复桌面的 `产品信息T.psb`。
5. 新商品数据需要涵盖该款实际会变化的字段。未绑定的母版内容会随副本保留，尤其要核对原款洗护、试穿、场景文案和颜色槽位。

## 新版裤子母版的表格

| 任务 JSON 中的 `tables` 键 | 母版模块 |
| --- | --- |
| `03选尺码` | `尺码 / 3`，S3 选尺码 |
| `05尺码快选` | `尺码 / 4`，S4 尺码快选 |
| `试穿报告` | `尺码 / 5`，S5 试穿报告 |

- 用该款的实际表头和完整矩阵。试穿报告保留源数据的字段含义，按新版位置映射可对应的字段，缺值留空。
- 以各区原圆角表底为容器，按实际列内容分配列宽，按有效数据行数调整行高和表高。维持表头和行标色、固定标题与单位的位置。每格保留原生文字，沿用下节逐字符字体规则。
- 超过该区的可读容量时，脚本会指出具体表格。核对后分表或适当扩高该模块再生成。未提供矩阵的区块隐藏，避免母版样例数据出现在成品中。
- 母版中的产品信息、颜色、图片和质检等仍需按款绑定。尤其核对示例货号和名称是否已替换。

## 逐字符字体

货号、材质、尺码范围以及两张尺码表使用以下字体。Photoshop 在同一原生文字层内记录字符字体，原有位置、字号和段落样式沿用母版。

| 字符 | 字体 |
| --- | --- |
| 数字 `1` 和 `%` | 阿里妈妈方圆体静态 SemiBold |
| 其他半角数字、英文字母、半角小数点、正号、短横线和空格 | G8321 Medium |
| 中文、`/` 和其他标点 | 方正兰亭中黑 GBK Regular |

执行前确认 Photoshop 可读取所需字体。任一缺失时，脚本会报告缺失字体。重开 PSD 后抽查 `1`、`%`、`-`、`/` 及其相邻文字的字体，并用文字工具试改。

Photoshop 预检使用 PostScript 名称 `KocoDetailFangYuan-SemiBold`、`G8321-Medium` 和 `FZLTZHK--GBK1-0`。如迁移到其他电脑，在 Photoshop 中安装技能 `assets/` 中对应字体。阿里妈妈方圆体使用 `KocoDetailFangYuan-SemiBold.ttf`，该文件沿用 JPG 版静态字形，使用独立名称区分系统已安装的可变字体。

## 旧版「产品信息T」母版定位示例

显式指定桌面的 `产品信息T.psb`（790 × 11657 px）时，沿用该版原生文字列和固定栅格。选尺码 6 列，尺码快选 8 列，均支持 1–7 行数据。列数含首列。更早的 `产品信息.psb`（790 × 11706 px）仍可显式指定，每表最多 7 行，选尺码最多 7 列，尺码快选最多 8 列。

| 字段 | 原始母版的图层路径 |
| --- | --- |
| 货号 | `产品信息 拷贝 2 / 组 844 / KQ26201 ` |
| 材质比例 | `产品信息 拷贝 2 / 组 844 / 100%` |
| 材质名称 | `产品信息 拷贝 2 / 组 844 /  聚酯纤维` |
| 尺码范围 | `产品信息 拷贝 2 / 组 844 / 110-170` |
| 选尺码 | `产品信息 拷贝 2 / 尺码 / 组 830 / 组 1266 / 组 1265` |
| 尺码快选 | `产品信息 拷贝 2 / 尺码快选` |

图层名保留前后空格，货号层名末尾一个空格，材质名称层名开头一个空格。两个尺码模块用 `tables` 矩阵回填。

## 旧版母版任务示例

下例使用旧的「产品信息」母版的实际图层路径。素材和表格只演示数据格式，运行前换成商品的实际文件及完整数据。相对文件路径以任务 JSON 所在目录为基准。

```json
{
  "template": "./产品信息.psb",
  "output": "./输出/KQ26157_详情长图.psd",
  "text": [
    {"path": ["产品信息 拷贝 2", "组 844", "小氧气格格绒卫衣   "], "value": "小氧气格格绒卫衣"},
    {"path": ["产品信息 拷贝 2", "组 844", "KQ26157"], "value": "KQ26157"}
  ],
  "images": [
    {"path": ["产品信息 拷贝 2", "华夫格卫衣_米白_15度侧视_图2"], "source": "./素材/米白.png"},
    {"path": ["模特", "组 1113 拷贝 2", "儿童户外草地商业大片 (7)"], "source": "./素材/户外.jpg"}
  ],
  "tables": {
    "03选尺码": [
      ["尺码", "衣长", "胸围"],
      ["110", "46.5", "80"],
      ["120", "49.5", "84"]
    ],
    "05尺码快选": [
      ["身高/体重", "15-19", "19-23"],
      ["100-110", "110码", "110码"],
      ["110-120", "120码", ""]
    ]
  }
}
```

`text`、`images`、`tables` 可按实际替换范围提供。使用尚未转换尺码表的原始 PSB 时，任务中要提供两个表格的真实数据，才能生成可编辑内容。输出使用新文件名。若 Photoshop 以 PSD 的 2 GB 数据限制拒绝保存，请把 output 扩展名改为 .psb，以保留母版全部原生图层和嵌入对象。自动换图要求替换后的构图边界与原槽位匹配，边界变化时会报错，应先按原智能对象画布适配素材。

## 旧版「产品信息」母版定位示例

| 字段 | 原始母版的图层路径 |
| --- | --- |
| 货号 | `产品信息 拷贝 2 / 组 844 / KQ26157` |
| 商品颜色文案 | `产品信息 拷贝 2 / 组 844 / 星云蓝/远山紫/奶霜米` |
| 单个颜色名 | `产品信息 拷贝 2 / 组 845 / 星云蓝` |
| 版型属性文案 | `产品信息 拷贝 2 / 组 1024` 下的文字图层及子组 |
| 尺码快选 | `产品信息 拷贝 2 / 尺码 / 05尺码快选` |
| 尺码表 | `产品信息 拷贝 2 / 尺码 / 组 830 / 03选尺码` |

图层名按原样匹配，商品名称图层末尾的三个空格也属于名称。图层名包含斜杠时，整个名字仍是 JSON 路径数组的一个元素。例如商品颜色文案绑定写作 `["产品信息 拷贝 2", "组 844", "星云蓝/远山紫/奶霜米"]`。试穿报告存在同级同名图层，自动绑定前需在母版副本内区分命名。手工改好的 PSD 若需按数据重新生成，也要把修改同步至任务 JSON。

## 执行

在技能的 `scripts` 目录下运行。这个入口使用 Python 标准库。自动执行选项需要 Windows 和已安装的 Photoshop。

```powershell
python build_editable_long_psd.py --job "D:\本批数据\商品任务.json" --run
```

也可仅生成 JSX，交给已连接的 Photoshop 执行，或在 Photoshop 中通过「文件 → 脚本 → 浏览」运行。

```powershell
python build_editable_long_psd.py --job "D:\本批数据\商品任务.json" --job-script "D:\本批数据\生成详情长图.jsx"
```

每款准备一份任务、一个独立输出路径。先以同款数据回填验证版式，再用行列数和场景比例不同的款验证替换。新版整页输出使用 PSB。

## 验收

- 打开保存后的 PSD，逐段核对画布尺寸、模块位置、模板装饰和文字对齐。
- 使用文字工具改一处商品字段、选尺码表及快选表各一格，并核对试穿报告。
- 在 Photoshop 中双击商品图、场景图的智能对象缩略图，核对图片内容和蒙版。把 PSD 移到另一目录重新打开，确认图片可见。
- 对照表格源数据检查表头、行列、单位、空值和小数。检查商品图、场景图等比裁切，确认图框内无露底、变形或切掉主体。
- PSD 保存失败时记录 Photoshop 返回的错误及对应商品。若超过 PSD 尺寸或体积限制，复核是否使用 PSB 交付。

# 原图回贴与验收

## 工作区与记录

保留干净原图。每人记录人物标识、参考归属、原图尺寸、裁切框 left/top/right/bottom、工作区尺寸、生成结果原生尺寸、面部蒙版及羽化范围。中间图保存到任务工作区，不覆盖用户原片。

裁切包含完整面部及判断帽檐、头发遮挡和脸颈关系所需的上下文，让大部分生成像素服务于面部。多人分开建立工作区，另一人的脸不进入当前允许编辑区。

生成结果与裁切框尺寸不同，保留原生文件，再按记录坐标回贴。仅当构图、尺度和角度一致时等比缩放；若头部被移动或重画，核对保护区中的可靠锚点。几何变化大时不任意拉伸新脸。

## Photoshop 图层

使用已有连接时遵守当前工具的状态检查和文档 ID 规则，不修改或关闭无关文档。建议层次：

- 原图中的必要前景遮挡或商品保护层（确实需要时）
- 人物 B 面部层＋独立蒙版
- 人物 A 面部层＋独立蒙版
- 完整干净原图底层

面部内容由实际图像编辑工具生成或由用户授权的实拍合成完成；通过独立面部层调色和蒙版融合，不把合成脚本称为生成模型。

蒙版覆盖需要更新的五官、脸颊和下颌，给边界必要的过渡空间，准确避开帽檐、商品、头发遮挡及不需修改的耳朵。新脸型确实需要改变轮廓时，计划中包含紧邻轮廓的小范围过渡，不能把所有修改锁在旧脸内部后声称已完成身份校正。

羽化按实际脸部像素尺寸和边缘状况设置；过宽会混入旧五官或形成双影，过窄会出现接缝。不把案例中的固定数值套到所有图。保留可编辑蒙版，不扁平化唯一源文件。

光影融合以原场景光源、帽檐遮光、脸颈肤色和锐度为依据，新五官的局部明暗可以变化。不做无必要的整图锐化、磨皮或重打光。

## 像素审计

保存无损合成 PNG，导出与最终实际面部蒙版一致的编辑范围图；将各蒙版合并，包含所有羽化非零像素。黑色表示保护，任何大于零的值表示允许编辑。不用 JPG 保存审计蒙版。

脚本只读图并输出 JSON，依赖 Pillow：

    python scripts/audit_composite.py --base "<原图>" --result "<无损合成PNG>" --mask "<合并编辑蒙版PNG>" --json-output "<检查结果JSON>"

使用透明通道承载蒙版时，显式增加 --mask-channel alpha。默认读取灰度值，白色背景的透明 PNG 不能直接冒充灰度编辑蒙版。

返回码：0 为保护区逐像素一致，1 为保护区有改动，2 为尺寸、蒙版或输入错误。全空或覆盖全图的蒙版不能提供本任务需要的有效保护范围，脚本会拒绝。

确保图像保持相同画布和预期色彩处理。JPEG 重压缩、全图缩放或全图色彩转换会影响比较，不能先修改原图以消除差异。用户需要 JPEG 时另外交付，并在无损版本上审计。

脚本不判断人物是否像、笑容是否自然或蒙版是否画对，也不自动修图。零保护区差异不能替代视觉验收；编辑区内零变化也不能证明已完成换脸。

## 最终查看

重新打开实际导出文件检查，不只看编辑器预览：
- 脸型及五官比例、年龄感符合指定实拍；未知角度或细节如实保留不确定性。
- 眼颊嘴角响应自然，牙齿和口腔没有明显异常。
- 帽檐阴影、脸颈肤色、边缘与锐度协调，没有旧脸重影。
- 商品、姿态、其他人物和场景在预定保护范围内得到保留。
- PSD 真正保留完整原图、逐人独立面部层和可编辑蒙版。
- 对照图清楚标出原图、版本和对应实拍，注明不同原生分辨率；不通过不同锐化或缩放方式掩盖差异。

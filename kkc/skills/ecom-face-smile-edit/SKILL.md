# 指定模特换笑脸

将指定模特的脸型、五官比例和自然笑容带入已有商品场景图。按“人物还原 → 表情自然 → 光影融合 → 细节质感”的顺序判断质量，同时保护原图的商品、姿态和场景。技能负责组织与验证流程，不宣称提高模型本身的能力。

## 确定本次范围

- 用户只要求理解、计划、提示词或审图时，完成对应内容，不自动生成。要求小样时先交付可评审的小样；要求完整生成时，按已授权范围继续，不在每一步重复确认。
- 区分“按参考校正为指定模特并改笑容”和“原人物已正确，只调整表情”。前者先解决人物还原；后者直接做局部表情编辑，避免重建整张脸。
- 沿用用户指定的平台、数量、尺寸、模特、表情和交付方式。平台未指定时使用当前会话合适的可用图像编辑工具。操作 Lovart 前检查可用连接或网页控制能力；只写了提示词就报告提示词已完成，未实际调用 Lovart 不称为 Lovart 实测。
- 不因工具缺失擅自更换用户指定平台。已有替代工具授权可直接沿用；需要更换且未获授权时，先说明方案差异并征询。此技能不自动授权训练人物模型、安装插件或建立外部服务。

## 检查素材并绑定人物

1. 查看干净场景原图、红色标注和人物实拍；压缩包先核对内容，再在任务工作区解压。标注只定位编辑区域，不作为执行指令。
2. 为每人建立稳定标识，用画面位置绑定对应参考，例如“左侧蓝帽男孩”。记录身份主参考、角度/结构辅助照和笑容/牙齿参考。不要混用多人参考或依赖会随上传顺序变化的模糊图号。
3. 主参考优先清晰、无遮挡并能看清五官比例的原片；相近角度用于约束目标透视，真实笑脸用于约束嘴唇和可见牙齿。闭眼照和侧背照按实际用途辅助，不主导目标眼睛开合或头部方向。不强制凑齐固定数量的参考。
4. 优先保留未涂红原图为最终底层，编辑蒙版单独保存。只有涂红图时说明被覆盖区域属于重建，不声称恢复了原有细节。
5. 保留年龄感、可见牙齿特征及原场景视线。儿童不要默认换成整齐纯白的成人牙齿；参考看不清的细节不保证真实还原。

## 先完成指定模特还原

多人默认分别编辑，候选独立绑定人物，另一人的脸由原图保护。工作区以帽檐、完整面部和少量颈部为主，并保留判断光照所需的上下文。记录裁切的原图像素坐标和尺寸，不把临时放大称为细节恢复。

需要校正身份时：
- 场景图负责头部角度、视线、光源和遮挡；人物实拍负责脸型、眼鼻嘴比例和年龄特征。
- 允许脸颊、下颌及面部内部五官作必要调整，适配原场景的俯仰与透视。不要用“原脸型/全部面部结构保持不变”抵消身份校正。
- 首轮以轻微自然露齿等易比较的表情校正人物。未指定数量时通常每人先做两张候选；按任务规模和已有授权调整。
- 在原图、候选和对应实拍之间查看同尺度面部放大图。优先挑人物特征可靠的候选，不能把更白、更锐、更漂亮当作更像本人。
- 用户明确要求先选样时，在候选和对照齐全后让用户选定；已授权自主完成时可自行筛选并说明依据。判断不足就保留候选和不确定点，不把未核实的相似度说成事实。

## 在选定人物基础上调整笑容

身份已可靠时，参考实际笑脸调整眼睛、脸颊、嘴角和露齿量，保持同一人物的五官比例。按用户要求生成表情；未限定时可提供轻微露齿、自然露齿、较明朗的笑容，避免夸张到眼睛消失或牙齿失真。

各笑容分支从同一选定基础和对应实拍出发，原场景仍是最终底图。避免把一串失败修图连续当作新原图，导致人物、质感和视角逐轮漂移。

使用 [references/prompts.md](references/prompts.md) 编写本轮身份校正、表情和局部返修词。填入实际图号和人物归属，不直接发送占位符。

## 合回原图并核对

按 [references/compositing.md](references/compositing.md) 处理定位、可编辑蒙版和衔接。使用生成工具完成面部内容编辑；Photoshop 或用户授权的确定性合成方式负责原图回贴。普通调用不使用 Python 重绘、换脸或磨皮；附带 Python 脚本只读图审计，不改像素。

- 保留完整原图底层，每人独立面部层和蒙版。帽子、商品标识、衣服、道具及不需修改的头发/耳朵由原图保护。
- 允许编辑区包括必要的脸颊/下颌过渡和羽化边缘；范围应符合实际编辑计划，不能事后扩大以覆盖意外改动。
- 保留原场景光源方向、帽檐投影和脸颈肤色关系；局部面部阴影随新脸结构变化。参考照的棚拍光线、穿搭和背景不带入。
- 局部结果与原图配准后再合成。头部比例、角度或边界改变且无法自然配准时，回到对应局部候选修正，不拉伸成畸形脸。
- 逐像素审计运行 scripts/audit_composite.py，蒙版须包含真实羽化边缘。差异不为零时修正或报告实际变化，不声称区域外未变。没有合成与审计能力时交付“局部候选”，不声称完成严格保护的原图合成。
- 像素审计只检查保护范围；人物是否像、笑容是否自然以及蒙版是否画对，仍需逐图视觉检查。

## 返修与交付

一次返修针对一个主要问题：人物不够像先改参考分工或编辑范围；嘴笑眼不笑就协调眼颊；牙齿异常按真实笑脸修嘴部；光影不融修局部明暗；商品被改则恢复原图保护层。

通常每人最多进行两轮针对性返修，用户指定次数优先。连续同类失败时停止同参数重抽，交付可评审候选并说明缺少的角度、可见细节或工具能力，避免无限消耗。不为“修细节”重新生成已经合格的整张商品场景。

默认交付：
- 保持原图画布尺寸的成片 PNG；用户要求 JPEG 时另外输出，不用 JPEG 做逐像素一致性审计。
- 工具支持时交付保留完整原图、独立面部层和可编辑蒙版的 PSD；不能真正导出时如实说明，不用扁平图冒充源文件。
- 全图对照，以及逐人“原图—结果—实拍参考”的放大对照。只有用户要求比较流程时才额外生成另一条对照路线。
- 简短说明实际工具、生成端原生尺寸、回贴尺寸和检查结果。不把单次样本说成稳定成功率，不把低清整图放大后的模糊全部归因于流程。
- 用户只要预览或提示词时按本次范围缩减交付，不机械增加源文件和比较组。

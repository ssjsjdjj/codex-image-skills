# 面料质感检查与修复

目标：**同面料整体检查 → 首轮按细腻目标修复 → 整件一致性验收**。用户要求修复时，默认直接以细腻修改版为交付目标，无需再次提出“做细腻一点”。保留正常受光、褶皱和景深。

细腻指：在摄影条件允许的原像素视图中能辨认有实拍依据的织纹，交付尺度下自然柔和；纹理的粗细、起伏、对比与实物相符，没有人为增加的粗黑点、凸起白边、厚重网格或锐化颗粒。它不是统一的细方格滤镜，也不是把真实粗织、绒感、网孔或光泽磨平。具体判断见 [check.md](references/check.md)。

## 工作入口

- 只检查时展示证据，不修图。已明确授权的范围直接执行；内部小样验收不新增用户确认环节。用户已授权整件目标面料修复时，覆盖其中全部已确认异常；同面料分组本身不是整组修改授权。新对象或超出授权的问题继续报告。
- 检查读 [check.md](references/check.md)；修复再读 [repair.md](references/repair.md)。仅在用工具或批量任务时读 [tools.md](references/tools.md)，不加载原商品差异skill、复杂批选网页或无关规范。
- 按图片、商品对象、同面料组定位。共享材质依据，逐图确认部件边界；外层、内搭、拼接和衬里分开。人物、Logo内容和版型不改；结构不明只暂停受影响部位。

## 执行要点

1. 实拍确定纹理类型、相对尺度、密度、起伏和光泽，首次候选就按此细腻目标制作；原AI保留动作和已核准内容。区分织纹、格纹、点状交点、真实通孔；不凭外观猜成分或性能。
2. 同组覆盖全部可见区域，分别标记正常、异常、待证、合理虚化或遮挡并写原因。发现一处异常后联查相邻与对应部位；没有覆盖记录不称全检。
3. 同面料保持纹理类型与合理连续性，允许随光照、透视、曲面和景深变化。检查腰头、前后片、暗褶、下摆、开衩、翻边及可见内侧；缝线、包边、Logo和遮挡边缘单独保护。正常部位保留；只修授权异常及必要融合区。
4. 先内部验证代表该材质/姿态/光照的小样，按细腻标准通过后继续其余异常。分别控制微纹理与原图颜色、光影、褶皱；用实际蒙版和坐标回贴限制修改。检查蒙版是否误含皮肤、其他面料或背景，不靠提示词或“蒙版外零改动”代替范围判断。
5. 从最终PNG和重新打开的PSD验收：参考符合、细腻程度、局部融合、整件一致、保护区完整。原像素查粗点、亮边和串界，交付尺度查整体自然度。小样通过不代表整组完成；失败保留有效基线，无新依据不反复生成。

## 精简与交付

同款参考和未变裁片缓存复用；逐图处理，避免多张高清图同时占内存。检查给简短分组清单和编号证据，默认不建网页；只重查变动区域、关联同面料组及整件预览。记录版本、范围、证据及未解决项即可。

修复只交付**PNG＋可编辑PSD**，默认原尺寸。PSD保留完整原图、当前有效基线、独立修复层及未烘焙的蒙版；两者同版并经复核。清理本次创建的临时辅助通道，保留原有有效透明度、用户通道和图层蒙版。中间裁片、JSON和候选放任务`work/`，不作为额外交付。程序校验不等于面料正确；记录模型实际目视结论，模型复核不写成人工确认或用户采纳。

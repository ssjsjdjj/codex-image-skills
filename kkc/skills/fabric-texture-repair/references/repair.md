# 异常修复与整件验收

## 范围与选法

固定原图、当前有效基线、同面料组和已授权异常。异常区及必要融合区组成允许蒙版，皮肤、头发、背景、Logo、其他材质、正常同面料和未授权区为保护区。口袋/走线位置错误属于结构问题：只报告障碍，继续不受影响的面料任务，不擅自改版型。

首轮候选、内部小样和正式交付均按同一[细腻目标](check.md#首轮细腻目标)检查，不为已有明确修复授权增加小样确认环节。若用户指定先预览，则按其流程；缺少实拍或关键材质依据时保留待证状态，不宣称已还原实物。

|条件|优先方法|限制|
|---|---|---|
|同姿态、真实细节能对齐|参考原像素局部回贴|核对方向、曲面、遮挡；不搬入另一姿态的褶皱/阴影|
|已有纹理轻微软|适度非生成清晰度处理|对照实际交付尺寸；过锐、噪点、描边不算细节恢复|
|局部油亮、色晕|局部光色校正|保留正常主光向、折边体积与底色，不把全件统一哑光|
|真实纹理明显丢失且依据足够|用当前可用图像编辑工具作受参考约束的局部重建，仅回贴合格补丁|这是有依据的重建，不是找回原像素；不接受默认整图替换|

遵循宿主图像编辑工具要求。按需读其编辑说明，不安装或调用未授权平台。候选与目标局部尺寸、位置、色彩空间不一致时先查原因，不自动拉伸、锐化或用大羽化掩盖。

先验证能代表该纹理、曲面和受光的一处；平展亮面通过，不能直接代表暗褶、膝弯或侧面。确认方法后处理同组剩余授权异常，不反复逐项索要授权。每个方法参数按图确定，不固定孔径、强度或羽化宽度。

## 细腻候选与强度控制

- 提示词明确目标材质、实际纹理类型、相对尺度、对比与起伏，以及原有褶皱/光向和保护对象。对实拍为细平织纹的款式，可描述“细线、细小交点、低起伏、自然低对比”，同时排除粗点、凸起白边和厚重格线；其他材质按其实际特征改写。
- 原图只是纹理丢失时，优先保留其大尺度颜色、光影和褶皱，只重建缺少的微纹理。若已有异常粗纹、颗粒或亮边，先在授权区域减弱这些异常，再补入合格细纹；不能在粗纹上叠加细纹，也不能只磨平后交付。
- 高频分离、混合强度与亮边压制可作为融合手段，按实拍和最终观感选择。检查高频中是否混入候选新增的缝线、轮廓或噪点；不把候选整块高通直接当织纹。各图、亮面与暗面分别判断，不将本批的半径、曲线、通道差或不透明度固化为通用值。
- 小样同时看原像素和整件效果：细节可信、不过重，周边色光连续且保护区无变化才继续。明显粗点或亮边问题在内部返修；不合格候选留在work，达标后正式交付。

## 回贴质量

- 色调/大尺度明暗与微纹理分别检查；保留原褶皱和光向。细纹不应压过接缝、印花和布面本身。
- 清晰度应符合参考及当前摄影条件；不得靠模糊整片、磨平纹理、缩小尺寸或压缩掩盖补丁。融合失败应调整候选、局部光色或蒙版，不能牺牲已正确区域换取表面均匀。
- 纹理随曲面和拉伸压缩变化，止于真实布片。避免黑波点、平面铺网、跨缝连续点阵、重复针脚和补丁接头。
- 蒙版约束实际像素；候选整图有变化时只取已验收局部。回贴后检查四周、融合带及正常对照区。替代候选互斥，不叠加旧补丁；重叠修改需合成成一份验证过的补丁。
- 蒙版本身也要验收：手指、肤色、包边、Logo、缝线、内搭和背景不能因多边形圈选而混入。颜色/通道辅助只能细化已确定边界，须检查阴影、相近颜色和细窄布面是否被误删或误留；不能照搬某一种颜色的通道公式。查看蒙版叠加及实际修前/修后差异，不能只验证“变化均在蒙版内”。
- 首次失败先定位原因，仅有新方法/证据时再试一次。仍不合格则保留有效基线和未解决状态；不无限重生、不丢弃此前有效修复。

## 最终验收

以实际最终PNG及重新打开的PSD为准，分别观察：

1. **参考符合与细腻程度**：纹理类型、孔型/点形、相对尺度、密度、方向、起伏和光泽有依据。实拍为细平织纹时，没有额外的粗黑点、凸起白边、厚重格线或颗粒；原像素下可辨细节，交付尺度下自然柔和。不能以纹理越显眼越好，也不能磨掉实物本有结构。
2. **局部融合**：颜色与受光连续，褶皱保留；四周无色带、晕边、残影、双线及串界。
3. **同组与整件一致**：全部可见同面料区域均有记录；异常已覆盖或明确未解决，正常对照区未退化；没有“修补区特别锐、旁边光滑”的新断层。正常景深和明暗差异允许保留。
4. **范围与文件**：保护区完整且实际蒙版未包含非目标对象；PNG与PSD同尺寸、同版本、同可见效果。PSD原图/基线完整，修复像素与独立图层蒙版可编辑；切换修复层能比较前后，停用蒙版能恢复所保存的候选像素。清理本次临时辅助通道，不误删原有用户通道、有效透明度或图层蒙版；检查重开后的整图没有异常透明。

原像素检查伪影，交付尺度检查整件观感。数值、哈希和文件校验只能证明范围/版本/可编辑性；缺少真实目视观察不标通过。修改PNG、PSD、蒙版或相关参考后重新验收受影响组及整件。未解决与待证不可被一处成功带着关闭。

## 输出与批量

每张修复图只交付同名同版本`.png`和`.psd`。默认原尺寸、保留透明度与色彩配置，不自动缩小或输出JPG。已有修复PSD优先追加图层；若以平面基线创建新PSD，原PSD另行保留，不覆盖。PSD尺寸/文件限制或缺失依赖导致无法交付时报告缺项，不静默合并、改PSB或降采样。

参考描述、方法小样及未变裁片可复用；具体蒙版、方向、密度与光照按图检查。逐图保存检查点，失败只停该图；同一PSD写入串行。内部记录放任务work，正式输出目录只放PNG/PSD。工具使用见[tools.md](tools.md)。
